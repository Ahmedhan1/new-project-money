## What NEXUS is
A local-first, **zero-spend** AI video production system (edit, remix, create-from-idea, animation, dubbing, series,
publishing packages, content factory) with a browser UI on `http://127.0.0.1:8765`. Identity and non-negotiables:
`PROJECT_BRIEF.md`. Python package `nexus/` (FastAPI + SQLite + FFmpeg + local models). Target user: one creator on Windows.

## Notes for the next agent
- Cloud containers are ephemeral: `.nexus`, models and the demo project are gone each session. Fast tests need only
  `pip install -r requirements-ci.txt`. Real runs: `pip install faster-whisper scenedetect sentencepiece piper-tts`, then
  models download on first use (Whisper small, MADLAD 3B 3 GB, Piper voices). Image generation needs a separate torch+diffusers
  folder (`docs/GENERATION.md`).
- Demo source: NASA id `iss061m2627771232_Live_Interviews_Jeanette_Epps_191004` (images.nasa.gov, `~medium.mp4`).
- Importing `nexus.api` starts an embedded worker thread (set `NEXUS_EMBEDDED_WORKER=0` for scripts) - see K-12.
- The local LLM is optional everywhere; without it back-translation and LLM titles are skipped and say so.
