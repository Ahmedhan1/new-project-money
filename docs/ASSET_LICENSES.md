# Asset licences

Generated by `scripts/maintenance/gen_asset_docs.py` from the manifest. Every asset is checked by
`assetlib.license_check` before install (allowed licence, commercial use confirmed, author, source and attribution
recorded; downloads need a pinned URL + SHA-256, and OFL fonts their licence text, which is downloaded and kept next to
the font). `tests/fast/test_a2_assetlib.py::test_manifest_is_valid_and_every_asset_has_licence_metadata` fails otherwise.

## Policy

- Allowed: CC0-1.0, OFL-1.1, Apache-2.0, MIT, CC-BY-4.0, PD-USGov, NEXUS-Proprietary
- Attribution text required: CC-BY-4.0
- Licence text must travel with the file: OFL-1.1, Apache-2.0, MIT
- `NEXUS-Proprietary` = renderer features that are part of NEXUS's own code (all rights reserved, see LICENSE; no separate file).
- Generated assets (CC0-1.0) are NEXUS's own work, made on your machine by `nexus/assetlib/generators.py`.

## Considered and not installed

| Resource | Licence | Why |
|---|---|---|
| Kenney UI Audio | CC0-1.0 | licence fits, but the download link is generated by the site's JavaScript; no pinned direct URL |
| Wikimedia Commons CC0 field recordings | CC0 / PD per file | per-file licence must be read through the Commons API, which rate-limits (HTTP 429) from shared cloud IPs; add from the owner's PC |
| NASA audio library | PD-USGov | items are hours-long launch/press recordings; would need trimming to be a useful SFX; use assets.search_images-style ingestion instead |
| Freesound.org | CC0 / CC-BY / CC-BY-NC per file | needs an API key (an account) and many files are NC (non-commercial) - owner decision |
| Commercial LUT/transition packs (Motion Array, Envato, etc.) | proprietary/subscription | paid or subscription - excluded by the zero-spend rule |
| RocketStock / Video Copilot free packs | custom free licence with redistribution limits | licence terms need owner review before bundling |
