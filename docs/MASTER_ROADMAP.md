## 5. Shared contracts

All additive. Unknown keys must keep being ignored. Cross-package imports are lazy and tolerate `ImportError`.

**Timeline** (dict, see `docs/PHASE3_PLAN.md` for the phase 3 keys). New keys an agent introduces are documented by WS A in
`docs/TIMELINE.md`. Every key that changes pixels or sound must be part of `render.segment_key`.
`render.render(tl, out, workdir, on_progress=None, draft=False, workers=None) -> stats`.
Audio items: `tl["audio"][i] = {"src","start","volume","role": "narration|sfx|ambience|music|dialogue","lang"?}`.

**Analysis** (`media/analyze.py` output, per source): `{"path","duration","video":{w,h,fps},"scenes":[(s,e)],
"segments":[{"start","end","text","words":[{"start","end","word"}],"speaker"?}],"silence":[(s,e)],"quality":{...},
"repetitions":[...],"scores":[...]}`. WS B may add keys (`shots`, `topics`, `speakers`, `moments`, `motion`), never remove.

**Director** (WS B): `director.profiles() -> dict`, `director.plan(analysis_by_src, brief) -> plan`,
`director.build(plan, size=(1920,1080)) -> tl`, `director.edl(tl, fmt="json|cmx3600") -> str`,
`director.direct(sources, analysis_by_src, brief) -> {"plan","master","edl","notes"}`.
`brief = {"profile","target_seconds","instructions","platforms":[...],"languages":[...],"shorts": n}`.
`plan["decisions"]` lists every kept and dropped span with a reason (the edit must be explainable).

**Shorts** (WS C): existing signatures stay. New: `shorts.select(analysis, *, time_range=None, topic=None, speaker=None,
durations=(30,45,60), top=10) -> [moment]`, `shorts.factory(src, analysis, *, n, platforms, variants=1, style=None) ->
[{"moment","variant","platform","timeline","why","scores","context_check"}]`.

**Platforms** (WS F): `platforms.names()`, `platforms.get(name) -> profile`, `platforms.tune(tl, name) -> (tl, notes)`,
`platforms.check(probe_or_path, name) -> {"ok","checks":[...]}`, `platforms.safe_zone(name, W, H) -> {top,bottom,left,right}`.
Profile fields carry `kind: documented|observed|experimental`, `source`, `read_on`.
Canonical names: `youtube`, `youtube_shorts`, `tiktok`, `instagram_reels`, `instagram_feed`, `facebook`, `snapchat_spotlight`.

**Languages** (WS D): `languages.yaml` packs keyed by BCP-47-style tag (`en`, `de`, `fr`, `ar`, `ar-EG`, `ar-Gulf`, `zh`,
`ru`, `hi`, …). `localize.packs()`, `localize.pack(tag)`, `config.font_for(tag)`, `config.font_name_for(tag)`,
`localize.qa_cues(cues, tag) -> report` (speech/packs.qa). A pack states for ASR, MT and TTS: model id, licence, `commercial_use: yes|no|unverified`.
A voice with `commercial_use != yes` is never selected silently.

**Media engine** (WS E): `encoders.detect() -> {"h264":[...],"hevc":[...],"av1":[...],"hw":[...]}`,
`encoders.video_args(codec="h264", quality="balanced", draft=False, hw="auto") -> list[str]`,
`export.profiles()`, `export.export(src, out, *, codec, quality, width, height, fps, max_bytes, on_progress) -> report`,
`export.verify(path, expect=None) -> report`, `proxy.ensure(src) -> Path`, `proxy.inspect(src) -> metadata`.
The original file is never modified or deleted.

**Quality** (WS G): `quality.score(path, tl=None, analysis=None, lang=None) -> {"score":0-100,"grade","verdict":
"premium|pass|needs_work|fail","categories":{visual,editing,audio,localization},"failed":[{"id","why","fix"}]}`.
A render that merely completed is never `premium`.

**Generation** (WS H): `generate.providers()`, `generate.capabilities() -> {"image","image_to_video","text_to_video",…:
{"available":bool,"why"}}`, `generate.image(prompt, **kw)`, `generate.video(...)`; every output records
`provenance = {"kind": "generated|animated_still|motion_graphics|footage|slideshow", "model","licence"}`.
