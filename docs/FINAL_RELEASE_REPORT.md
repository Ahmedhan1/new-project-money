## 4. Wan 2.2 TI2V-5B on Kaggle (`kaggle_primary`, no other account, no paid compute)

Model `Wan-AI/Wan2.2-TI2V-5B-Diffusers` @ `b8fff7315c768468a5333511427288870b2e9635`, Apache-2.0; diffusers 0.35.2 (pinned).
Measured environment: 2 × Tesla T4 (14.56 GiB, sm 7.5), 31.35 GiB RAM, torch 2.11.0+cu130, transformers 5.20.2;
BF16 not native on T4 (a BF16 matmul works by emulation).

Strategy (D-22), each step found by a real failure, not assumed:
1. Text encoder (UMT5-XXL, BF16) on GPU1; all prompts encoded, then freed (first attempt kept a second reference →
   OOM on GPU1, fixed).
2. Transformer FP16, **layer-sharded**: blocks 0–14 on GPU0, 15–29 on GPU1.
3. VAE FP32: I2V image encode on GPU0; decode on GPU1 with our first-chunk-aware tiling (diffusers 0.35.2 `tiled_decode`
   drops `first_chunk` and `unpatchify` for the Wan 2.2 VAE and crashes; untiled decode needs ~3.5× more memory at
   720p). Tiled vs reference decode on the same latents: **44.55 dB PSNR** (Kaggle, real weights).
4. Guards: NaN/Inf latents, black or flat output → failure, nothing exported. Never falls back to the 1.3B model.
